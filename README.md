# App Ideas

A collection of app ideas, competitor analyses, and full-build project plans.

Each idea includes:
- Competitor breakdown & what makes them tick
- Honest feasibility assessment (what can be built vs what's a moat)
- Complete infra design (architecture, DB schema, API routes, AI agent design)
- Tech stack, build timeline, and cost estimates
- MVP scope vs future phases

## Contents

| File | Description |
|---|---|
| `prospectzero.md` | Signal-based LinkedIn prospecting agent — analysis + full infra design |

## Purpose

This repo exists so I can pull any idea off the shelf and start building immediately. No re-thinking the architecture. No re-researching competitors. Just execute.

## Folder Structure Pattern (Per Idea)

Every idea follows the same infra design template:
- Architecture diagram
- Directory structure
- Full PostgreSQL schema
- REST API routes
- AI agent design (when applicable)
- Tech stack decisions with rationale
- Build timeline per phase
- Monthly cost estimates
- Future scaling roadmap
